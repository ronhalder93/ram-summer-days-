# Premium RGB Keyboard

Native Android input method with an HTML/CSS RGB key surface.

## Build APK in GitHub Actions
1. Open the repository Actions tab.
2. Select **Build Premium RGB Keyboard APK**.
3. Run workflow on branch `premium-rgb-keyboard-apk`.
4. Download the `PremiumRGBKeyboard-debug-apk` artifact from the completed run.
5. Extract the artifact ZIP to get `app-debug.apk`.

## Install and enable
Install the APK on Android. Open Premium RGB Keyboard, tap **Set Up Keyboard** and enable it, then tap **Switch Keyboard** and select it.

## RGB themes
Open **Keyboard Settings — RGB Styles** in the app and select a fixed palette. There is no automatic rainbow cycling.

## Notes
This is a starter build and should be tested on-device before daily use. It currently provides basic letter typing, space, backspace, and enter; it does not yet implement a full symbol/number layout, autocorrect, suggestions, or password-field-specific UX.
